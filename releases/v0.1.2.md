Scribe Seek now renders its Windows interface on the CPU and presents it through Win32 GDI. This addresses the severe interface and cursor stutter observed with the previous OpenGL renderer.

### Improved

- The Windows executable no longer creates an OpenGL context or loads an application GPU rendering backend.
- The event loop waits when idle and coalesces input-driven frame requests to the monitor's refresh interval.
- Unchanged scenes skip CPU rasterization and presentation. Uncovering the window restores its retained bitmap.
- Font and image updates are retained while minimized, so restoring the window keeps its text and controls intact.

### Fixed

- Restored the waveform application icon in the title bar and taskbar, and embedded a multi-resolution icon in the EXE.
- Kept the existing local transcription, playback, language settings and in-app update workflow.
