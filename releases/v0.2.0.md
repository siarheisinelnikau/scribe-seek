Scribe Seek now offers a saved Light / Dark appearance choice alongside its six interface languages.

### Added

- Switch between Light and Dark in **Settings → Appearance**. The choice applies immediately and is restored on the next launch.
- A coherent dark palette for the library, recording transcript, search highlights, playback controls, dialogs, progress and error states.
- Real client-area screenshots of both themes and the English, Russian and French interfaces, captured with the application's production CPU rasterizer.

### Improved

- English, Russian, French, German, Spanish and Italian remain available in **Settings → Interface language**, independently of speech recognition language. Appearance controls and update-failure guidance are translated in all six.
- Existing settings preserve the selected language, speech language, model and startup-update preference. Settings created before this version use the Light theme until another choice is selected.
- The startup failure dialog follows the saved interface language when storage can be opened.
- Normal text, action labels and transcript search highlights have contrast regressions for both palettes. Layout checks now cover both themes at the supported window sizes in all six languages.

### Verification

- Formatting, catalog/placeholder validation, Clippy and focused automated tests were run locally.
- Screenshots use an isolated sample transcript and a finite offscreen render; they do not verify OS input, native dialogs, audio output or normal visible/hidden-window performance. Those interactive/runtime checks were not repeated for this version.
